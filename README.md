## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13, standard library only) copies the pre-rendered
`entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png` (or `/output/entry.png`) and
verifies its SHA-256. `render.py` (Pillow, build time only) draws the image
from scratch: masthead, date line, lead hero, 2×2 grid, strip and sources
footer.
